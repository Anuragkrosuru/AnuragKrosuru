### Selected projects

#### [Polymarket CopyLab](https://github.com/Anuragkrosuru/polymarket-copylab)
A Python research toolkit for observing public market data and evaluating paper-trading strategies. Includes wallet screening, simulated copy trading, an arbitrage scanner, a BTC strategy experiment, and combined reporting.

**Engineering focus:** persistent ledgers, concurrent data collection, execution checks, and reproducible reporting. Simulated results are kept separate from evidence of live execution or profitability.

#### [Distributed Search Engine](https://github.com/Anuragkrosuru/SearchEngine)
A search system over **20,000+ HTML documents**, combining TF-IDF and PageRank with a MapReduce indexing pipeline. A search service aggregates results from three index servers.

**Python · Flask · SQLite · MapReduce · Multithreading**

#### [Instagram Clone](https://github.com/Anuragkrosuru/InstagramClone)
A full-stack social application with a React interface and Flask REST API. Features include authentication, infinite scrolling, likes, comments, and image uploads.

**React · JavaScript · Flask · SQLite · AWS**
